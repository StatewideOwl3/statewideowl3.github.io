# My Portfolio Website

This is my personal portfolio website showcasing my background, skills, projects, and interests. The site features an interactive cosmic theme with orbiting navigation elements and smooth animations.

## Features

- Interactive 3D universe background
- Orbital navigation system
- Responsive design
- Project showcase
- Skills visualization
- Contact form
- Text analyzer tool

## Technologies Used

- HTML5
- CSS3 (with animations and transitions)
- JavaScript (vanilla)
- Three.js for 3D animations
- GSAP for smooth animations
- Font Awesome for icons

## View the Site

Visit [https://statewideowl3.github.io](https://statewideowl3.github.io) to see the live site.
